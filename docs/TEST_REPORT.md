## Межі тестів API
13 результатів включають хешування пароля/config та 11 сценаріїв усередині HTTP-suite. Виконано справжні Express middleware/маршрути через HTTP із підміненою тестовою реалізацією Mongoose-операцій. Тестове сховище потрібне лише для перевірки контрактів, не входить у production-запуск.
Перевірено:
- валідацію паролів/email, захист від об’єктів у рядкових полях, заборону анонімного workspace;
- реєстрацію, код, одноразовість, пароль під час підтвердження, відмову неправильному паролю;
- білий список публічних полів і приватність телефону/налаштувань;
- підміну owner_id, чужі зміни, pending-модерацію й повторну модерацію;
- обране та повторне створення того самого чату;
- приватність чатів, підміну sender_id, idempotency client_id повідомлень;
- дозволені медіа, власність фото, заборону чужих приватних tickets;
- блокування обох напрямків відправлення;
- reset пароля й відкликання сесій, неправильний і повторно використаний код;
- відмову неналаштованому OAuth, прив’язку одноразового grant до verifier;
- заплановані каскади видалення;
- серверні ліміти запитів.
Це НЕ підтверджує реальну атомарність, TTL, індекси чи конкурентність MongoDB. Для цього є окремий npm run test:integration у backend. Він не використовує ваш Atlas URI, а запускає ізольовану тестову базу.

Спроби реальної MongoDB: 8.0.17 завершилася SIGABRT через недоступну інформацію CPU у tcmalloc; 7.0.24 завершилася code 100 / Operation not permitted при ініціалізації. Жодна з цих спроб не дала зеленого інтеграційного тесту. Не приховувати цю межу перед запуском.

## UI / HTTP
JSDOM виконує експортований вебкод Expo SDK 58 із mocks шрифтів і частини браузерних API. Локальний сценарій: вхід/реєстрація UI, правила пароля, добровільна згода, модальне відновлення, вкладки, профіль, публічний перегляд, телефон, чат, створення заявки, перезапуск.
Окремий remote-сценарій використовує справжній fetch до Express: signup → код із тестового mailer → сесія → профіль → налаштування → перезапуск зі збереженою сесією й повторним читанням API. Серверне сховище цього тесту у пам’яті. Це не візуальний браузерний тест і не мобільний тест.
Тестові адреси/секрети живуть лише в сценаріях тестування; dist-api не входить у ZIP. Не публікуйте dist-api як користувацьку вебверсію.

## Залежності
Expo audit moderate-зауваження стосуються транзитивного ланцюжка Expo/fingerprint/minimatch. Несумісний автоматичний downgrade SDK не застосовувався. npm audit fix --force не запускати без аналізу. Audit не є повним аудитом безпеки.

## Що перевірити до першої відкритої бети
Реальна Atlas replica set, TTL/індекси/транзакції, одночасні повідомлення й видалення, cold start Render, мережеві відмови, live email delivery, OAuth callback/replay/cancel, конфігурація дозволів Atlas, CORS, фактичне видалення фото, iPhone Safari/Expo Go, великий шрифт і клавіатура, резервні копії, ліміти сервісів.
