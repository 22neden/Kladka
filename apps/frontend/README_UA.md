# Мобільна / вебчастина Kladka.UA v1.2
Основна інструкція — ../README_UA.md. Почніть із кореня KLADKA: npm.cmd run setup, npm.cmd run init-env.
У цій папці працюють Expo SDK 58 і React Native. Сервер знаходиться в ../backend. База — MongoDB через Express.
Не запускайте expo у backend і не копіюйте MONGODB_URI в EXPO_PUBLIC_*.
